# DSH 白板 Plus (@kewen/dsh-whiteboard-plus)

DeepSeek Harness (DSH) 社区可视化白板增强插件，基于无限画布与 Plait 绘图引擎构建。

## 特性 (Features)
- 🎨 **思维导图与架构图**：开箱即用的专业脑图与流程图自由绘制。
- ♾️ **无限画布**：自由缩放、平移与形状组件，支持浅色/暗黑双模态玻璃拟态设计。
- ⚡ **DSH 右侧栏沉浸式集成**：无缝嵌入 DSH 交互体系，支持分屏协作与一键唤起。
- 🔒 **本地优先 (Local-First)**：画布数据持久化于本地工作区（`~/.dsh/whiteboards/`），无外部云端依赖与安全泄露风险。
- 🛡️ **严格遵守 dsh-std/v1 规范**：完全解耦，零上游代码侵入。

## 安装与使用
1. 在 DSH 插件目录或配置文件中安装本插件。
2. 重启 DSH 后，在右侧面板的“新建标签页 (+)”或会话顶部工具栏中点击 **“白板”** 即可启动。
